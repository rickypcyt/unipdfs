# University

Aquí van tus asignaturas. Al arrancar, la app crea `Assignment 1` … `Assignment 5`.

```
University/
  Assignment 1/
    Tema 1/            <- tus PDFs, .tex y .md
    Tema 2/
  Assignment 2/
```

Renombra las carpetas como quieras (p. ej. `Redes`, `Álgebra`) y crea las que necesites.
El contenido de esta carpeta no se sube a git (ver `.gitignore`).
